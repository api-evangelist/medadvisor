# MedAdvisor - Pharmacy Unified API

> MedAdvisor (MedAdvisor Solutions) is an Australian-founded, ASX-listed medication
> management and patient-engagement technology company whose pharmacy workflow software
> runs in the large majority of Australian community pharmacies. The Pharmacy Unified API
> is a JWT-secured HTTP REST surface for dispense workflow, service/appointment booking,
> eScript (electronic prescription) handling, refill/order management, the pharmacy
> PlusOne inbox, and patient communication, including a documented "3rd-Party Integration"
> family for external widgets and eCommerce platforms.

## APIs

- [Pharmacy Unified API - Swagger](https://pharmacy-unified.api.medadvisor.com.au/swagger/): Interactive API reference.

## Authentication

- JWT bearer token. Obtain via POST /api/v1/account/3rdpartylogin using an issued
  clientId + clientSecret plus Base64-encoded (UTF-8) pharmacy credentials, then send
  Authorization: Bearer {token} on every call.

## Capabilities

- 3rd-Party Integration: partner login, pharmacy lookup, eScript status by token, order notification into the PlusOne inbox.
- Booking Service: available services, time slots, create/edit/cancel bookings, resources and calendars.
- Refill Order: pending/completed orders, line items, eScript tokens, complete/refund/reminder/return-to-stock.
- Inbox: main/sent/completed/scheduled/ready-to-collect queues.
- Pharmacy & Head Office: settings, registration/activation, e-prescribing settings, multi-pharmacy service push.
